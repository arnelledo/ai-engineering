# Investigate Change

Investigate the requested feature, bug, or change before modifying production code.

Do not implement anything yet.

## Required Analysis

Determine:

1. Relevant execution path
2. Relevant files and components
3. Callers and dependencies
4. Current behavior
5. Expected behavior
6. Persistence and database side effects
7. External integrations
8. Transaction concerns
9. Concurrency concerns
10. Existing tests

If this is a defect, determine the root cause rather than stopping at the first plausible explanation.

If this involves migrated functionality, inspect the authoritative legacy implementation and identify behavioral differences.
